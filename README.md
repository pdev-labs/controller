# PSP Controller

A web-based Universal Gamepad that turns your mobile device into a virtual Xbox 360 controller or Keyboard/Mouse on your PC. Originally designed to replicate the PSP layout, it now features fully customizable layouts, haptic feedback, gyroscope support, and multiple themes (Xbox Series, SNES, PlayStation).

## Features
- **Virtual Xbox 360 Gamepad**: Emulates a native Xbox controller on Linux.
- **Universal Keyboard/Mouse**: Send keyboard and mouse inputs perfectly.
- **Gyroscope Support**: Use your phone's tilt sensors as analog sticks.
- **Fully Customizable Layout**: Drag, drop, and resize buttons on your phone.
- **Haptic Feedback**: High-quality vibration responses on touch.

## Installation

### Linux
Download the latest `.AppImage` from the [Releases](https://github.com/pdev-labs/controller/releases) page.
1. Make it executable: `chmod +x psp-controller-*.AppImage`
2. Double click to run!
*(Note: On first launch, it will prompt you for your password to install the required `uinput` Xbox drivers.)*

### Windows & macOS
Download the `.exe` or `.dmg` from the Releases page. 
*Note: Due to operating system limitations, Xbox controller emulation is disabled on Windows and macOS. Only the Keyboard/Mouse functionality will work out-of-the-box.*
